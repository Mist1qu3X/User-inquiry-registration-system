# InquiryDesk — система регистрации обращений пользователей

Учебный сквозной проект по дисциплине «Технологии разработки приложений на
базе фреймворков». Консольное приложение для регистрации и учёта обращений
пользователей: приём обращения, отнесение его к категории, отслеживание
статуса обработки.

## Предметная область

Основные сущности:

- **Пользователь (User)** — автор обращения.
- **Обращение (Inquiry)** — запрос пользователя (тема, текст, дата).
- **Категория (Category)** — тематический раздел обращения.
- **Статус (Status)** — состояние обработки обращения.

## Структура проекта

```
main.py            — консольное меню сценариев
inquiries.py       — операции над обращениями (в т.ч. функции ПР1)
categories.py      — операции над категориями
statuses.py        — операции над статусами
users.py           — операции над пользователями
storage.py         — загрузка и сохранение данных в JSON
utils.py           — безопасный ввод с клавиатуры
data/              — JSON-файлы с данными
tests/             — автотесты (pytest)
requirements.txt   — зависимости проекта
```

## Возможности (ПР2)

- регистрация обращений и хранение их в JSON;
- категории и статусы обращений, поиск и фильтрация;
- изменение статуса и закрытие обращения;
- сортировка обращений по дате;
- меню сценариев и обработка ошибок ввода.

## Запуск

```bash
python main.py
```
