# InquiryDesk — система регистрации обращений пользователей

Учебный сквозной проект по дисциплине «Технологии разработки приложений на
базе фреймворков». Консольное приложение для регистрации и учёта обращений
пользователей: приём обращения, отнесение его к категории, отслеживание
статуса обработки.

## Предметная область

Основные сущности:

- **Пользователь (User)** — автор обращения.
- **Обращение (Inquiry)** — запрос пользователя (тема, текст, дата).
- **Категория (Category)** — тематический раздел обращения.
- **Статус (Status)** — состояние обработки обращения.

## Текущий этап (ПР1)

Реализован начальный консольный сценарий. В модуле `inquiries.py` определены
три базовые функции:

1. `can_register_inquiry` — проверка возможности регистрации обращения;
2. `get_inquiry_state` — определение состояния обращения;
3. `format_inquiry_card` — формирование краткой карточки обращения.

## Запуск

```bash
python main.py
```

## Дальнейшее развитие

Проект развивается по практическим работам: модульная структура и хранение
данных в JSON (ПР2), объектная модель на классах (ПР3), затем веб-реализация.
